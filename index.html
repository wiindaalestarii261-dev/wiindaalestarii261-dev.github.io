Undangan Digital 💌

Platform undangan digital berbasis web yang interaktif, elegan, dan ramah lingkungan. Didesain secara responsif untuk pengalaman terbaik di smartphone maupun desktop para tamu undangan.

HTML5 / Modern CSS Responsive Web Design Interactive RSVP Visual Animation
  • Personalisasi nama tamu otomatis via URL parameter
  • Musik latar romantis dengan kontrol audio intuitif
  • Integrasi Google Maps untuk petunjuk lokasi acara
  • Formulir ucapan & konfirmasi kehadiran langsung (RSVP)
